# RogueHalla

RogueHalla is a multiplayer arena roguelike: up to eight players pick a faction, loot, farm mobs and fight until one is
left standing. It is being ported from a legacy TypeScript game (Colyseus server, Phaser client, in `packages/`) to an
authoritative **Rust server** and a **Unity Web client**. The legacy game is the reference: the Rust side proves itself
against captures of it.

The Rust server decides every outcome. The Unity client draws what the server tells it and holds no game rules; its one
exception is local walk prediction, mirrored from Rust and always corrected by the server.

## Run the Rust server locally

You need the Rust toolchain (pinned in `rust-toolchain.toml`; rustup installs it on first use). From the repository root:

```sh
cargo build --workspace
cargo test --workspace      # rh-persist's tests need DATABASE_URL (eval "$(tools/pgtest/start.sh)") or RH_SKIP_PG_TESTS=1
cargo run -p rh-server -- --self-signed --fill-bots 4 --min-players 1 --fill-seconds 2
```

Then open `https://localhost:7777/probe` and accept the self-signed certificate. To check Rust against the captured
legacy scenarios: `cargo run -p rh-parity --bin parity-report`. More commands (headless runs, browser proof) are in
[CONTRIBUTING.md](CONTRIBUTING.md).

## Run the Unity client locally

The C# library needs only the .NET 8 SDK, not Unity:

```sh
dotnet test client-unity/RoguehallaNet.Tests
bash client-unity/sync-net.sh --check     # the Unity copy of the library is up to date
```

The Unity project itself needs Unity 6 (6000.0.85f2). Build the Web client with
`client-unity/UnityProject/Tools/build-web.sh`, start `rh-server --first-playable`, serve
`client-unity/UnityProject/Build/Web`, and open it with `?server=ws%3A%2F%2F127.0.0.1%3A7777%2Fws`. The full steps are in
[client-unity/README.md](client-unity/README.md) and [client-unity/UnityProject/README.md](client-unity/UnityProject/README.md).

## Run the legacy game

`npm install` then `npm run dev` (server on :2567, client on :5173). Everything about the legacy game, its rules,
controls, commands and hosting is in [docs/legacy/LEGACY_GAME_README.md](docs/legacy/LEGACY_GAME_README.md).

## The gate

`scripts/gate.sh --quick` while you work; `scripts/gate.sh` before hand-off. It is the definition of done. See
