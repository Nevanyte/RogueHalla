## 1. ID and outcome
The engine-free library assumes 50 ms in its walk prediction (`LocalMotion.cs` `TickMs`, `LocalMotion.AttackPause.cs`,
`LocalMotion.Alignment.cs`), vision timing (`Vision.cs` `TickMs`) and render clock (`RenderClock.cs` default). When this
lands each reads the session's rate from Welcome (`Session.cs` already sets `Clock.TickMs` from `w.TickRate`), and the
Rust-generated prediction vectors exist at both rates: `protocol/fixtures/server_walk_v3.json` and
`ranged_pause_v3.json`, each carrying `tickMs`, generated by the commands that make v2 today. The client predicts and
reconciles correctly against a 40 Hz server.
